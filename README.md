# Paris Group Copilot

Copiloto de venture studio para discovery e execução de MVPs com IA.

## Documentação

- [Enquadramento do problema](docs/enquadramento.md) — contexto, dor, hipótese de
  valor, métrica de validação e fora de escopo. É o contrato intelectual do produto:
  toda feature precisa ser justificável por este documento.

## Rodando localmente

```bash
npm install
npm run dev
```

Acesse http://localhost:3000
